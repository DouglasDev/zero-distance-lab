# Mahakala artwork

Mahakala, Protector of the Tent, Central Tibet, ca. 1500. Metropolitan Museum of Art, object 78195 (2012.444.4), Zimmerman Family Collection, Gift of the Zimmerman Family, 2012. The Met marks this image Public Domain.

Source: https://www.metmuseum.org/art/collection/search/78195
Image: https://images.metmuseum.org/CRDImages/as/web-large/DP291219_edt.jpg
